# AI Interior Designer 3D 🛋️✨

โปรเจกต์สำหรับจำลองการตกแต่งห้องแบบ 3 มิติบนเว็บเพจ ผสมผสานพลังของ **AI (Gemini 1.5 Pro)** ในการวิเคราะห์และแปลงแปลนบ้าน 2 มิติ (รูปภาพ) ให้กลายเป็นห้อง 3 มิติโดยอัตโนมัติ พร้อมระบบตกแต่งภายในด้วยโมเดล 3D คุณภาพสูงจาก **Poly Haven**

## ✨ ฟีเจอร์หลัก (Key Features)

- 🤖 **AI 2D to 3D Generation:** อัปโหลดภาพแปลนบ้านหรือภาพสเก็ตช์ด้วยมือ แล้วให้ AI ประมวลผลโครงสร้างห้อง (กำแพง, ประตู, หน้าต่าง) ออกมาเป็น 3 มิติในไม่กี่วินาที
- 🎨 **Custom Materials:** เปลี่ยนสีผนัง (รองรับ Hex Code และ Color Picker) และเปลี่ยนลายพื้นผิวต่างๆ (ไม้, กระเบื้อง, ปูน, ลาเต้) ได้แบบ Real-time
- 🔍 **Poly Haven 3D Library:** ค้นหาเฟอร์นิเจอร์คุณภาพสูงจากคลังแสง Poly Haven ผ่าน API ได้โดยตรง (เช่น พิมพ์ค้นหา `sofa`, `chair`, `table`)
- 📦 **Smart 3D Furniture Placement:** ดึงไฟล์ 3D (GLB/GLTF) เข้ามาวางในห้องจำลอง พร้อมระบบฟิสิกส์ลากจัดวางบนแกนพื้น (XZ Plane) ป้องกันโมเดลลอยหรือจมพื้น
- 👁️ **Multiple Viewing Modes:** สลับมุมมองได้อย่างอิสระ ไม่ว่าจะเป็นโหมดพิมพ์เขียวมุมสูง (Blueprint), มุมมอง 3 มิติอิสระ (3D Orbit), หรือมุมมองบุคคลที่หนึ่ง (First Person)
- 📸 **Snapshot & Night Mode:** มีระบบถ่ายรูปห้องเก็บไว้ (Export as PNG) และโหมดกลางคืน (Night Mode) ที่จะเปิดไฟจำลองแสงในห้องให้โดยอัตโนมัติ

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

* **Frontend:** Next.js (React), TailwindCSS, Three.js (`@react-three/fiber`, `@react-three/drei`)
* **Backend:** Python, FastAPI, httpx
* **AI & APIs:** Google Gemini 1.5 Pro API (วิเคราะห์รูปภาพ), Poly Haven API (ดึงโมเดล 3D)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (How to run)

โปรเจกต์นี้แบ่งออกเป็น 2 ส่วนที่ต้องรันคู่กัน (เปิด 2 Terminal)

### 1. ฝั่ง Backend (FastAPI + AI API)
ทำหน้าที่เป็นตัวกลางในการเชื่อมต่อกับ Poly Haven และประมวลผลคำสั่ง API
```bash
# 1. เข้าไปที่โฟลเดอร์ backend
cd backend

# 2. ติดตั้งแพ็กเกจที่จำเป็น
pip install -r requirements.txt

# 3. รันเซิร์ฟเวอร์
uvicorn main:app --reload
```
> เซิร์ฟเวอร์จะรันอยู่ที่ `http://localhost:8000` 

### 2. ฝั่ง Frontend (Next.js)
หน้าเว็บหลักที่ใช้แสดงผล 3D และติดต่อผู้ใช้งาน
```bash
# 1. ตั้งค่า API Key ของ Gemini (ถ้ามีไฟล์ .env)
# NEXT_PUBLIC_GEMINI_API_KEY="your-api-key-here"

# 2. อยู่ที่โฟลเดอร์หลัก (3D-mockup)
npm install

# 3. รันหน้าเว็บ
npm run dev
```
> หน้าเว็บจะรันอยู่ที่ `http://localhost:3000`

## 📝 หมายเหตุ
* โมเดลจาก Poly Haven จะมีความละเอียดสูง (ระดับ 1K - 4K) เมื่อกดดึงโมเดลเข้าฉาก อาจจะต้องรอสัก 2-5 วินาทีเพื่อให้ระบบดาวน์โหลดไฟล์โมเดลเสร็จสิ้น (จะมีสถานะ Loading แสดงขึ้นมา)
* ระบบฟิสิกส์การจับวางเฟอร์นิเจอร์ถูกออกแบบมาให้ขยับซ้ายขวาและหน้าหลังได้อย่างเดียวเพื่อความสะดวกในการจัดวาง หากต้องการลบหรือหมุน สามารถเลือกที่ปุ่มเครื่องมือที่โมเดลได้เลย
